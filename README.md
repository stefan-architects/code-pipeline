## 2. 🔄 CI/CD Learning Goals
- **Continuous Integration (CI):** Implement automated build and testing workflows using AWS services.
- **Continuous Delivery/Deployment (CD):** Design and build deployment pipelines with AWS CodePipeline and CodeDeploy.
- **Quality Assurance:** Improve software reliability through automated validation and testing.
- **Process Automation:** Reduce manual effort across build, test, and deployment stages.
- **Monitoring and Logging:** Monitor application health, deployment activities, and system events through centralized logging and observability practices.
- **AWS DevOps Practices:** Apply AWS operational best practices, deployment strategies, and rollback mechanisms.
- **Documentation and Troubleshooting:** Use official AWS documentation to validate configurations and resolve issues.

## 3. 📡 DevOps Technology Stack
- **CI/CD & Version Control:** AWS CodePipeline, AWS CodeBuild, AWS CodeDeploy, Git, GitHub
- **Security & Access Management:** IAM Policies, IAM Roles, Amazon S3 Bucket Policies
- **Storage:** Amazon S3
- **Monitoring & Logging:** Amazon CloudWatch, CloudWatch Logs

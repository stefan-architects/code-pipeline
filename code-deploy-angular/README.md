## 1. 🌐 AWS CodeDeploy Website
Building off of the previous lecture for CodeBuild, I'm learning how to use AWS CodeDeploy with AWS CodePipeline and CodeBuild to deploy the Angular application to an EC2 Instance instead of an S3 bucket.

## 2. 🎓 CodeDeploy Learning Objectives
- Understand CodeDeploy and intergrate it with CodePipeline.
- Configure EC2 for deployments with CodeDeploy.
- Providing deployment scripts and installation configs to CodeDeploy with source code
- Monitoring deployment logs on EC2 and stream to Amazon CloudWatch Logs for log-term storage
- Deploy multiple instances behind auto scaling and a load balancer
- Understand how in-place all-at-once deployment work
- Understand how in-place rolling deployments and automated rollback work
- Understand what blue/green deployment are and how they work

## 2. 📐 CodeDeploy Resources To Be Utilized
| Service | Purpose |
| --- | --- |
| AWS CodePipeline | Automated the CI/CD deployment workflow |
| AWS CodeBuild | Built, test, and package application code |
| Amazon S3 | Store pipeline artifacts and host static websites |
| AWS IAM | Manage service roles and permissions |
| Amazon CloudWatch | Monitor pipeline executions, build logs, and errors |
| Amazon EventBridge | Triggered pipeline executions in response to events or schedules |
| GitHub | Source code repository host |
